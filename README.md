# Malhawi — Portfolio

Personal portfolio website built with HTML, CSS and vanilla JavaScript.

**Live site:** [malhawi.github.io](https://malhawi.github.io) *(update with your actual URL)*

## Stack
- Pure HTML / CSS / JS — zero dependencies, zero build step
- Google Fonts: DM Sans + DM Serif Display
- Hosted on GitHub Pages

## Features
- Pastel minimal design
- Filterable project cards (Full Stack / Systems / Security / Algorithms)
- Scroll-reveal animations
- Fully responsive (mobile + desktop)
- Mobile nav menu

## How to run locally
Just open `index.html` in your browser — no server needed.
